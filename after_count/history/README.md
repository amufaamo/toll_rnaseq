# after_count archive

This directory contains retired `after_count` snapshots, local R session
files, generated test output, and command-history JSONL files. Current source
files remain in `../app.R` and `../R/`.

Archive layout:

- `stable_2026-04-23/`: frozen application snapshot formerly stored at the
  repository root as `after_count_stable_2026-04-23/`.
- `*.bak*`: dated source snapshots formerly stored beside current source files.
- `after_count_session_*.RData`: old R workspaces.
- `after_count_*.Rhistory`: old command histories.
- `after_count_*_Rplots_*.pdf` and `after_count_test_*.pdf`: generated output.
- `*.jsonl`: command logs generated by the application, if present.

Everything in this directory is ignored by Git except this README.
